입력 순서 가이드
1. 기본 정보 확인 자산번호, 물품명, 모델명은 OCR 결과가 들어와도 한 번 더 검토합니다.
2. 관리 정보 채우기 관리부서와 비치장소는 실제 운영 기준에 맞게 직접 확인 후 입력합니다.
3. 실사용자 정보 선택 입력 배정 전 자산이면 비워두고 등록해도 되도록 안내를 명확히 둡니다.
